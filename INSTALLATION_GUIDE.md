## 🔓 Step 2: Enable Installation from Unknown Sources

### For Android 8.0 and Above:

1. After downloading, tap on the APK file
2. You'll see a prompt: "For your security, your phone is not allowed to install unknown apps from this source"
3. Tap "Settings"
4. Toggle ON "Allow from this source"
5. Press back button
6. Continue to Step 3

### For Android 7.x and Below:

1. Go to **Settings**
2. Tap **Security** (or **Security & Privacy**)
3. Find **Unknown Sources**
4. Toggle it ON
5. Confirm if prompted
6. Continue to Step 3

### Troubleshooting:

**Can't find the setting?**

- Try: Settings → Apps → Special Access → Install Unknown Apps
- Look for your browser or file manager in the list
- Enable installation from that app

## 🐛 Troubleshooting

### Problem: "App not installed"

**Possible Causes & Solutions**:

1. **Insufficient Storage**

   - Check available space (need 100MB+)
   - Delete unused apps/files
   - Try again

2. **Corrupted Download**

   - Delete the APK file
   - Download again
   - Ensure stable internet during download

3. **Previous Version Conflict**

   - If you have an older version installed:
   - Go to Settings → Apps → Tower Desk
   - Tap "Uninstall"
   - Try installing again

4. **Android Version Too Old**
   - Check your Android version: Settings → About Phone
   - Need Android 6.0 or higher
   - Consider updating OS if possible

### Problem: "Parse Error"

**Solutions**:

- Re-download the APK (file may be corrupted)
- Ensure complete download (check file size)
- Check if APK is compatible with your device
- Contact support with device details

### Problem: App Crashes on Startup

**Solutions**:

1. **Force Stop and Restart**:

   - Settings → Apps → Tower Desk
   - Tap "Force Stop"
   - Open app again

2. **Clear App Data**:

   - Settings → Apps → Tower Desk
   - Tap "Storage"
   - Tap "Clear Data"
   - Open app again

3. **Reinstall**:

   - Uninstall app completely
   - Restart device
   - Install APK again

4. **Report Issue**:
   - If still crashing, contact support
   - Include: Device model, Android version, error message

### Problem: Cannot Enable Unknown Sources

**Solutions**:

- Your device may have restrictions (corporate/school device)
- Check if you have admin rights
- Contact your device administrator
- Try installation via ADB (advanced users)

### Problem: "Installation Blocked"

**Causes**:

- Device policy restrictions
- Google Play Protect warning

**Solutions**:

1. **Tap "More Details"**
2. **Choose "Install Anyway"**
3. Or temporarily disable Play Protect:
   - Open Play Store
   - Tap menu → Play Protect → Settings
   - Toggle OFF "Scan apps with Play Protect"
   - Install APK
   - Re-enable Play Protect after installation

## 📱 Device-Specific Instructions

### Samsung Devices

1. Install may ask for "Install Unknown Apps" permission
2. Go to Settings → Apps → Default Apps → Special Access
3. Find "Install Unknown Apps"
4. Enable for your browser/file manager

### Huawei Devices

1. Settings → Security → More Settings
2. Enable "Install apps from external sources"
3. Select your browser/file manager

### Xiaomi/Mi Devices

1. Settings → Additional Settings → Privacy
2. Enable "Unknown Sources"
3. May need to enable "Install via USB" if transferring from PC

### OnePlus Devices

1. Settings → Security → Unknown Sources → ON
2. Or: Settings → Apps → Special Access → Install Unknown Apps
