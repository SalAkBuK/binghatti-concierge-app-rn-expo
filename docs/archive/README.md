# Archive

This directory contains non-runtime reference material that was moved out of the repo root during stabilization.

Current buckets:

- `api/` for older API specs and option docs
- `design/` for exported design/reference bundles such as Stitch downloads
- `diagnostics/` for logs, profiling dumps, and crash captures
- `notes/` for historical improvement and performance writeups
- `source-backups/` for old code snapshots and recovered files
- `tasks/` for task exports and audit artifacts

Do not add active feature code here. If an archived document becomes current again, move it back into a more intentional location under `docs/`.
